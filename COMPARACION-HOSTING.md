# Comparación de publicación

## GitHub Pages
- Costo inicial: US$0 con GitHub Free para repositorios públicos.
- Ideal para: sitio institucional estático.
- Ventaja: costo mínimo.
- Limitación: no es un backend; no debe usarse por sí solo para almacenar usuarios, contraseñas o expedientes.
- Dominio propio: compatible.

## Vercel
- Hobby: US$0/mes, orientado por Vercel a proyectos personales/no comerciales.
- Pro: US$20/mes según la página de precios consultada el 3 de octubre de 2026.
- Ideal para: aplicaciones que luego usarán funciones del lado del servidor y despliegue continuo.
- Ventaja: evolución más sencilla hacia una aplicación completa.
- Consideración: para un despacho profesional, revisar condiciones del plan comercial.

## Recomendación para este proyecto
1. Publicar la página pública con GitHub Pages si la prioridad es gastar lo mínimo.
2. Mantener el módulo privado separado y conectarlo a un servicio seguro de autenticación/base de datos.
3. Si se decide centralizar todo en una plataforma full-stack, evaluar Vercel Pro o el hosting tradicional que ya tenga contratado el despacho.
